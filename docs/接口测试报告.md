## 三、发现的代码问题（专业测试价值）

1. **RabbitMQ 消息序列化失败**（高优先级）
   - 文件：`ResourceController.java:109`
   - 错误：`SimpleMessageConverter only supports String, byte[] and Serializable payloads`
   - 原因：`ResourceDownloadMessage` / `ResourceAuditMessage` 未实现 `Serializable`，且未配置 `Jackson2JsonMessageConverter`。
   - 影响：下载接口返回 500，MQ 消费者未触发。
   - 建议：在 `RabbitMQConfig` 中注入 `Jackson2JsonMessageConverter`。

2. **中文搜索 URL 编码问题**
   - 搜索接口对非 ASCII 参数敏感。
   - 前端若直接拼接中文会失败。
   - 建议：后端可加 `@RequestParam` 解码或文档明确要求前端 encodeURIComponent。

3. **重复注册 / 业务错误返回 HTTP 200**
   - 符合设计（GlobalExceptionHandler 对 BusinessException 返回 200），但前端需统一判断 `body.code != 200`。

4. **ES 索引**
   - 服务启动时成功创建 `resource` 索引，但测试中因 URL 问题未真正执行查询。
