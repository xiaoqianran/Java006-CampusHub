## 一、已修复的 Bug

### 1. RabbitMQ 消息序列化失败（下载/审核接口 500）—— **已彻底修复**

**根本原因**：
- `ResourceDownloadMessage` / `ResourceAuditMessage` 未实现 `Serializable`
- 未配置 `Jackson2JsonMessageConverter`，默认 `SimpleMessageConverter` 不支持 POJO
- `LocalDateTime` 序列化缺少 `JavaTimeModule`

**修复内容**（[RabbitMQConfig.java](/teamspace/studios/this_studio/006-CampusHub/shiqian-resource/src/main/java/com/shiqian/resource/config/RabbitMQConfig.java)）：

```java
@Bean
public MessageConverter jacksonMessageConverter() {
    ObjectMapper mapper = new ObjectMapper();
    mapper.registerModule(new JavaTimeModule());
    return new Jackson2JsonMessageConverter(mapper);
}

@Bean
public RabbitTemplate rabbitTemplate(ConnectionFactory cf) {
    RabbitTemplate t = new RabbitTemplate(cf);
    t.setMessageConverter(jacksonMessageConverter());
    return t;
}
```

同时两个 DTO 实现 `Serializable` 作为双保险。

**验证结果**：
- 下载接口从 500 → **200** 成功
- MQ 消息正确发送，消费者可正常接收

### 2. 中文搜索 URL 编码问题（400 Bad Request）—— **已解决**

测试脚本已改为使用 `urllib.parse.quote` 正确编码中文参数。

搜索接口现在可正常返回 200。
