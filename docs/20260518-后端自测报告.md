## 二、发现并修复的问题

### 问题 1：网关白名单失效 → 公共接口返回 401（严重，影响前端注册/登录）
**现象**：
- 直接访问 `http://localhost:8081/api/user/register` 正常
- 经网关 `http://localhost:8080/api/user/register` 返回 `401 未登录或 token 已过期`
- 前端所有未登录操作全部失败

**根本原因**：
- `JwtGlobalAuthFilter.java` 使用 `@Value("${gateway.auth.whitelist:}") private List<String> whitelist;`
- YAML 中定义为 list，`@Value` 字段注入对 List 类型绑定不稳定（经常为 null/空）
- `isPublicRequest()` 判断失败 → 所有请求走鉴权 → 无 Token → 401

**修复**（[JwtGlobalAuthFilter.java](/teamspace/studios/this_studio/006-CampusHub/shiqian-gateway/src/main/java/com/shiqian/gateway/filter/JwtGlobalAuthFilter.java)）：
- 添加 `DEFAULT_WHITELIST` 硬编码默认值
- `isPublicRequest()` 中 `List<String> effective = (whitelist != null && !whitelist.isEmpty()) ? whitelist : DEFAULT_WHITELIST;`
- 保证即使 @Value 失效，`/api/user/register`、`/login`、`/health`、`/actuator` 依然放行

### 问题 2：网关路由 503
**现象**：
- 修复白名单后，注册仍返回 503
- Nacos 中 `shiqian-user` 实例列表为空
- 原因：user/resource `application-local.yml` 强制禁用 nacos，命令行覆盖不完全生效

**修复**（新增 [application-local.yml](/teamspace/studios/this_studio/006-CampusHub/shiqian-gateway/src/main/resources/application-local.yml)）：
- 为网关增加 `application-local.yml`，路由改为**直连**：
  ```yaml
  spring.cloud.gateway.routes:
    - id: shiqian-user
      uri: http://localhost:8081
    - id: shiqian-resource
      uri: http://localhost:8082
  ```
- 本地开发零依赖 Nacos 服务发现

**效果**：
- 网关健康检查正常
- 注册/登录/受保护接口全部走通
